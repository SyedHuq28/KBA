NOCTX prompt

The no-context prompt was:

Answer the following question to the best of your knowledge.

Question: {question}

This prompt does not expose REFUSE or CONFLICT behavior. In the paper, we therefore treat NOCTX as a parametric-knowledge leakage diagnostic rather than as a conflict-aware baseline. Its purpose is to test whether substituted answers can be recovered without documents, not to provide a fair three-way triage comparison.

FaithRAG-style CoT / B6 prompt
Task Description:
Given a question and a context, triage the relationship between the evidence and the question.
Respond ONLY in the JSON format shown below.

You MUST reason through these steps before answering:
1. [Self-Evidence Extraction]: List specific facts from the context that address the question.
2. [Fact Analysis]: Check if extracted facts are consistent or explicitly contradict each other.
3. [Context Check]: Judge if the documents provide one answer, multiple answers, or no answer.
4. [Final Verification]: Choose the label — ANSWER, REFUSE, or CONFLICT.

Triage Labels:
- ANSWER: Context is consistent and provides one grounded answer — write the actual answer text.
- REFUSE: Context lacks sufficient information — write exactly: "Not enough information."
- CONFLICT: Context contains contradictions — write exactly: "Documents contain conflicting information."

Response Format:
{ "Reason": "1. [Self-Evidence Extraction]: ... 2. [Fact Analysis]: ... 3. [Context Check]: ... 4. [Final Verification]: ...", "Answer": "answer text OR exact refuse/conflict string" }

---
Example 1 (ANSWER):
Question: What colour is the sky?
Context: The sky appears blue due to Rayleigh scattering.
{ "Reason": "1. [Self-Evidence Extraction]: Sky is blue (Rayleigh scattering). 2. [Fact Analysis]: One consistent fact. 3. [Context Check]: Exactly one answer. 4. [Final Verification]: Mode is ANSWER.", "Answer": "Blue" }

Example 2 (REFUSE):
Question: What is the mass of Zelonite?
Context: Zelonite is found in volcanic regions.
{ "Reason": "1. [Self-Evidence Extraction]: No mass mentioned. 2. [Fact Analysis]: No relevant facts. 3. [Context Check]: Context does not answer the question. 4. [Final Verification]: Mode is REFUSE.", "Answer": "Not enough information." }

Example 3 (CONFLICT):
Question: Boiling point of Zelonite?
Context: Lab A says 340C. Lab B says 415C.
{ "Reason": "1. [Self-Evidence Extraction]: Lab A (340C), Lab B (415C). 2. [Fact Analysis]: Different values, contradiction. 3. [Context Check]: Two contradictory answers. 4. [Final Verification]: Mode is CONFLICT.", "Answer": "Documents contain conflicting information." }
